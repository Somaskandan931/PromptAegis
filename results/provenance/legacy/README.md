# Superseded claim registry

`claim_registry_600_scenario_study.json` belongs to the earlier 600-scenario controlled benchmark
(registry version 2.0). It points at `results/governance/governance_benchmark_20261017T061036Z.json`,
which is not part of the current record, and it was built from a dirty worktree. It is kept only so the
earlier execution history is not silently lost.

Do not cite it and do not combine its numbers with the development-split study. The current registry
is `results/provenance/claim_registry.json`, built by `experiments/study/build_claim_registry.py`.
